# Tride Registry Layer

## 作用

本目录承接 `TrideBusinessStrategyRegistry`、`TrideProductRegistry` 和 `TrideCodeRegistry` 的工作型资料。

## 真源优先级

1. `../../AGENTS.md`
2. `../../README.md`
3. 本目录中的登记文档

## 当前文件

- `business-state.md`：Tride 的商业定位、默认职责与边界
- `product-state.md`：Tride 的产品状态、模块职责与依赖
- `code-state.md`：Tride 的代码结构、健康状态与风险

## 更新规则

- 只有在用户明确要求“记录”或“更新”时才修改本目录。
- 总商业模式问题仍应优先回到 `TriMetaverse/BusinessStrategy`。
